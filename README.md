# Abhijith Krishnan Portfolio

My personal portfolio for software development, interactive projects, and digital media work. I designed and built this site to give recruiters and collaborators a direct route to working demos and source code.

Live site: https://portfolio-site-nu-green.vercel.app/

## Highlights

- Project cards with live demos and repository links.
- Responsive pages covering my software and creative work.
- A contact path for opportunities and collaboration.

## Stack

Next.js, React, TypeScript, and Tailwind CSS. The site is deployed on Vercel.

## Run locally

Requires Node.js and npm. From the repository root, run npm install and then npm run dev. Open http://localhost:3000.
